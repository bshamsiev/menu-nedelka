# «Что приготовить?» — меню на неделю (веб-приложение для телефона)

Приложение составляет меню на неделю для семьи, список покупок и стоимость в сумах.
Работает в браузере, устанавливается на iPhone и Android как приложение, работает без интернета.
Общее меню для всей семьи подключается по желанию: каждая семья использует свою бесплатную базу Supabase.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | само приложение |
| `data.js` | продукты, цены, рецепты, базовый минимум — правьте здесь |
| `manifest.webmanifest`, `icons/` | название и значки для установки на телефон |
| `sw.js` | офлайн-режим |
| `supabase.sql` | код таблицы для общего меню семьи (тот же, что в инструкции внутри приложения) |

## Где размещён сайт
Основной адрес: **https://bshamsiev.github.io/menu-nedelka/** (GitHub Pages, бесплатно, без лимита на число обновлений).
Старый адрес https://menu-nedelka.netlify.app показывает плашку «Приложение переехало» с кнопкой «Перенести мои данные» (плашка включается автоматически на любом адресе *.netlify.app).

### Первая публикация на GitHub Pages
1. github.com → **+** → New repository → имя `menu-nedelka` → **Public** → Create repository.
2. В новом репозитории: **uploading an existing file** (или Add file → Upload files) → перетащите все файлы из архива **и папку `icons`** → Commit changes.
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты сайт откроется по адресу https://bshamsiev.github.io/menu-nedelka/

### Сообщения «Что нового»
При каждом выпуске в `index.html` увеличивается `APPV` и в список `LOG` добавляется запись с 1–4 строками о главном. Пользователи, обновившиеся с прошлых версий, при первом открытии видят окно «Что нового»; новые пользователи — нет.

### Как обновлять
Репозиторий `menu-nedelka` → Add file → Upload files → перетащите новые файлы (с заменой) → Commit changes. Через минуту обновится сайт. Номер версии в `sw.js` уже увеличен в каждом новом архиве.

## Как установить на телефон
- **iPhone:** открыть сайт в Safari → «Поделиться» (квадрат со стрелкой; в компактном виде Safari — «•••» рядом с адресом) → «На экран «Домой»» → «Добавить».
- **Android:** открыть сайт в Chrome → меню ⋮ → «Установить приложение» (или кнопка «Установить приложение» внизу страницы).

## Общее меню семьи (Supabase)

Без подключения всё хранится только на телефоне. Чтобы семья видела одно меню и отмечала купленное, один человек делает один раз (≈10 минут):

1. Регистрируется на https://supabase.com (тариф Free, карта не нужна).
2. Создаёт проект (New project), выбирает ближайший регион, ждёт 1–2 минуты.
3. SQL Editor → New query → вставляет код из `supabase.sql` (или кнопкой «Скопировать код» в приложении) → Run. Если появится предупреждение Potential issue detected — Run query: код ничего не удаляет.
4. **Ключ:** шестерёнка Project Settings → API Keys → блок Publishable key → значок копирования у `sb_publishable_…` (в старых проектах — `anon public`). Secret keys не трогать.
   **Адрес:** Integrations → Data API → блок API URL → Copy (`https://xxxx.supabase.co/rest/v1/` — окончание приложение уберёт само). Enable Data API должен быть включён. Второй способ: зелёная кнопка Connect вверху.
5. В приложении, раздел «Общее меню семьи», вставляет оба значения → «Подключить».
6. Нажимает «Отправить приглашение» и пересылает ссылку семье. Остальные открывают ссылку и нажимают «Подключиться». **На iPhone** (проверено): приложение на экране «Домой» хранит данные отдельно от Safari, поэтому подключение из Safari туда не переносится. Порядок: открыть ссылку в Safari → установить приложение («Поделиться» → «На экран «Домой»») → открыть его со значка → вставить ссылку-приглашение в поле «Есть ссылка-приглашение?» (есть кнопка «Вставить из буфера»). На Android установленное приложение подхватывает подключение само.

Важно:
- **Никогда не используйте secret key** (`sb_secret_…`) или `service_role` — приложение их не примет.
- Ссылка-приглашение и publishable key дают доступ к меню семьи: не публикуйте их в открытых чатах. Один проект Supabase — одна семья.
- Бесплатный проект Supabase приостанавливается после недели без использования. Данные сохраняются; разбудить — кнопкой Resume project на supabase.com. На бесплатном тарифе — не больше двух активных проектов на аккаунт.
- Изменения расходятся между телефонами в течение ~15 секунд. Если двое правят одновременно, сохраняется последнее изменение.

## Мои блюда (каждая семья сама)
В приложении, раздел «Мои блюда»: форма по шаблону (название, приём пищи, тип, кухня, время, порции, техника, продукты с количеством на весь рецепт, шаги, ссылка). Новая кухня, техника или продукт появляются в анкете и в «Не люблю» вместе с блюдом. Блюдо без продуктов можно сохранить с примерной ценой порции — тогда оно учитывается в бюджете приблизительно. Есть разбор текста рецепта через ИИ (кнопка «Скопировать запрос для ИИ»). На Android установленное приложение появляется в меню «Поделиться» (например, из Pinterest). Свои блюда видны всей семье при общем меню.

## Как добавить или изменить встроенные блюда и рецепты
Все блюда, продукты, цены и базовый минимум — в файле `data.js` (рецепты — блок `R`, по одной строке на блюдо; формат описан в комментарии над ним).
1. Измените `data.js` (или попросите Claude — он пришлёт новый архив).
2. Увеличьте номер версии в `sw.js` (`menu-vN` → `menu-vN+1`).
3. Netlify → ваш проект → Drop new files → архив или папка → Publish new version.
Пользователи получат новые блюда автоматически при следующем открытии приложения (иногда со второго раза). Их меню, отметки и настройки сохранятся.
**Не переименовывайте существующие блюда**: сохранённые меню, правила и «любимые» ссылаются на название — блюдо со старым названием из них исчезнет. Лучше добавить новое.

## Ограничения
- Цены по умолчанию — ориентировочные для Ташкента (часть — Корзинка, часть — оценки). Каждый может поправить свои в разделе «Цены продуктов».
- Рецепты — краткие; у части блюд есть ссылки на пошаговые фото на eda.ru, у остальных — ссылка на поиск.
- Свинины в базе рецептов нет.
