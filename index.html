Как готовим

Остатки получают только блюда, которые хорошо хранятся и разогреваются: супы, плов, рагу, паста.

Общее меню семьи

Без подключения меню хранится только на этом телефоне. Чтобы вся семья видела одно меню и отмечала купленное, нужна бесплатная база данных Supabase. Настраивает один человек, один раз, примерно за 10 минут. Остальные подключаются по ссылке-приглашению.

Как настроить: пошаговая инструкция
  1. Зарегистрируйтесь в Supabase. Откройте supabase.com, нажмите Start your project и войдите через почту или GitHub. Тариф Free бесплатный, карта не нужна.
  2. Создайте проект. Нажмите New project. Имя — любое, например menu. Придумайте пароль базы и сохраните его: в приложении он не нужен, но пригодится вам. Регион выберите ближайший, например Central EU (Frankfurt). Подождите 1–2 минуты, пока проект создаётся.
  3. Создайте таблицу для меню. В меню слева откройте SQL Editor, нажмите New query, вставьте код ниже и нажмите Run. Должно появиться Success. No rows returned. Если Supabase покажет предупреждение Potential issue detected, нажмите Run query: код только создаёт таблицу для меню и правила доступа к ней, ничего не удаляет. 
    create table if not exists public.family_state (
  id text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.family_state enable row level security;
grant select, insert, update on public.family_state to anon;
do $$ begin
  if not exists (select 1 from pg_policies where tablename = 'family_state' and policyname = 'family read') then
    create policy "family read" on public.family_state for select to anon using (true);
  end if;
  if not exists (select 1 from pg_policies where tablename = 'family_state' and policyname = 'family insert') then
    create policy "family insert" on public.family_state for insert to anon with check (true);
  end if;
  if not exists (select 1 from pg_policies where tablename = 'family_state' and policyname = 'family update') then
    create policy "family update" on public.family_state for update to anon using (true) with check (true);
  end if;
end $$;
  4. Скопируйте ключ. Слева внизу нажмите шестерёнку Project Settings → API Keys. В блоке Publishable key, в строке default, нажмите значок копирования справа от ключа sb_publishable_… Копируйте только этой кнопкой: ключ длинный и на экране обрезан. Вставьте его в поле «Publishable key» в приложении. Блок Secret keys ниже не трогайте.
  5. Скопируйте адрес проекта. Он на другой странице: в том же меню слева, в разделе Integrations, откройте Data API (или слева значок Integrations → Data API). В блоке API URL нажмите Copy и вставьте адрес в поле «Адрес проекта» как есть: окончание /rest/v1/ приложение уберёт само. Переключатель Enable Data API на этой странице должен быть включён (зелёный). Второй способ найти адрес: зелёная кнопка Connect вверху экрана.
  6. Нажмите «Подключить» в приложении. Приложение проверит связь и перенесёт ваше текущее меню в общее.
  7. Пригласите семью. Нажмите «Отправить приглашение» и перешлите ссылку в семейный чат. На Android достаточно открыть её в Chrome и нажать «Подключиться». На iPhone приложение на экране «Домой» хранит данные отдельно от Safari: установите приложение, откройте его со значка и вставьте ссылку в поле «Есть ссылка-приглашение?».

Важно. Никогда не вставляйте сюда secret key (sb_secret_…) или service_role: приложение его не примет. Publishable key и ссылка-приглашение открывают доступ к вашему меню: делитесь ими только с семьёй. Бесплатный проект Supabase засыпает, если им не пользоваться неделю; данные сохраняются, а разбудить его можно кнопкой Resume project на supabase.com.

Установить на телефон

Приложение уже установлено на этом устройстве.

После установки приложение открывается со своим значком, без адресной строки, и работает без интернета (кроме синхронизации общего меню).

iPhone: откройте сайт в Safari → кнопка «Поделиться» (квадрат со стрелкой; в компактном виде — «•••» рядом с адресом) → «На экран «Домой»» → «Добавить». Если вы подключались к общему меню в Safari, откройте приложение со значка и вставьте ссылку-приглашение ещё раз.

Android: откройте сайт в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

История изменений

Цены по умолчанию ориентировочные, для Ташкента; поправьте их в разделе «Цены продуктов». Данные хранятся на вашем телефоне и, если подключено общее меню, в вашем собственном проекте Supabase.
